# Final-Project
大四畢業專題

## 後端操作方法
### 進入後端資料夾
```bash
cd backend
```
### 第一次使用
1.在backend加入.env檔
```env
SUPABASE_URL=你的 Supabase URL
SUPABASE_KEY=你的 anon/public key
SUPABASE_SERVICE_ROLE_KEY=你的 service_role key，只能放後端
```

2.建立虛擬環境
```bash
python -m venv venv
```
或
```bash
python3 -m venv venv
```
### 啟動虛擬環境
Windows(CMD)
```bash
.\venv\Scripts\activate.bat
```
Windows(PowerShell)
```bash
.\venv\Scripts\activate.ps1 	     
```
Mac/Linux 
```bash
source venv/bin/activate
```
啟動後會看到前面有(venv)
### 安裝套件
```bash
pip install -r requirements.txt
```
或
```bash
pip3 install -r requirements.txt
```
如果要使用影片/音檔轉逐字稿功能，另外安裝：
```bash
pip install -r requirements-transcription.txt
```
### 啟動 FastAPI
```bash
uvicorn main:app --reload
```

## 測試逐字稿 API
啟動後端後，可以用下面指令上傳短影片或音檔測試：
```bash
curl -X POST "http://127.0.0.1:8000/lectures/1/transcribe" \
  -F "file=@/path/to/test-video.mp4" \
  -F "language=zh" \
  -F "model_size=tiny" \
  -F "save_to_db=false"
```

確認轉錄結果正常後，把 `save_to_db` 改成 `true` 就會嘗試寫入 `transcripts` table。

如果要直接用 YouTube 連結轉逐字稿：
```bash
curl -X POST "http://127.0.0.1:8000/lectures/1/transcribe-youtube" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://www.youtube.com/watch?v=影片ID",
    "language": "zh",
    "model_size": "tiny",
    "save_to_db": true
  }'
```

## 啟用影片備份與 Pipeline 狀態

Pull 到含影片備份功能的版本後，先到 Supabase SQL Editor 執行：

```text
backend/sql/lecture_backup_and_pipeline_status.sql
```

這份 migration 會新增：

- Lecture 的 YouTube Video ID、檔案 Hash 與備份狀態欄位
- `lecture_generation_status`，保存每個 AI 步驟的狀態與錯誤
- 私有的 `lecture-video-backups` Storage bucket
- 同一 Course 內 YouTube Video ID／檔案 Hash 的唯一索引

後端可選環境變數：

```env
SUPABASE_VIDEO_BACKUP_BUCKET=lecture-video-backups
VIDEO_BACKUP_MAX_BYTES=2147483648
AI_REQUEST_TIMEOUT_MS=120000
GEMINI_CONTENT_FALLBACK_MODEL=gemini-2.5-flash
GENERATION_STALE_MINUTES=10
YOUTUBE_DOWNLOAD_ATTEMPTS=3
```

未設定時會使用上面的預設值。`requirements-transcription.txt`
包含影片備份合併音影所需的 FFmpeg 執行檔，不需要另外用 Homebrew
安裝。Storage bucket 必須保持 private，學生播放器會透過 FastAPI
取得短效 signed URL，不應改成公開 bucket。
